VocalTuneBtw: real-time pitch correction for monophonic vocals, built natively
for Linux.

**Fixes audio popping in 0.1.0.** Version 0.1.0 shipped a latency reduction
that caused audible pops on real vocals. 0.1.1 removes it, so latency is back
to 5.5 / 8.6 / 12.5 ms (High / Normal / Low voice range). If you installed
0.1.0, replace it with this version.

![VocalTuneBtw](https://raw.githubusercontent.com/PluginsBTW/VocalTuneBtw/v0.1.1/docs/images/note.png)

This is an early prototype. Detection, scale snapping, correction and pitch
shifting work and are covered by automated tests, and it has been used in
Bitwig Studio. It hasn't yet been evaluated systematically on recorded vocals.

## Download and install

Download `VocalTuneBtw-0.1.1-linux-x86_64.tar.gz` below, then:

```bash
tar -xzf VocalTuneBtw-0.1.1-linux-x86_64.tar.gz
mkdir -p ~/.vst3 && cp -r VocalTuneBtw-0.1.1-linux-x86_64/VocalTuneBtw.vst3 ~/.vst3/
```

Rescan plugins in your host. The archive also contains a Standalone app
(`VocalTuneBtw`) that runs without a host.

Requirements: Linux on x86-64 with glibc 2.43 or newer and libstdc++ from
GCC 13.2 or newer, plus ALSA, FreeType and fontconfig. This build was made on
Arch Linux, so it runs on Arch and other up-to-date rolling distributions.
It won't load on older systems such as Ubuntu 24.04 or Debian 12; there,
build from source (see below).

## What's in it

- Key and scale snapping: 12 roots, 14 scales, and per-note on/off on the
  keyboard.
- Retune Speed (1–200 ms) with Natural and Hard presets, Humanize, Strength,
  Detune (±100 cents) and Reference A4 (415–466 Hz).
- Tuning meter with the target note and deviation in cents.
- Latency at 48 kHz: 5.5 ms (High), 8.6 ms (Normal) or 12.5 ms (Low voice
  range), reported to the host for delay compensation.
- Click-free bypass; mono and stereo.

Only VST3 and Standalone are included. CLAP builds from source but hasn't been
tested in a host yet.
