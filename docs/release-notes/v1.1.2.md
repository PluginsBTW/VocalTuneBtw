VocalTuneBtw: real-time pitch correction for monophonic vocals, built natively
for Linux.

**A shorter version label.** The version in the bottom-right corner now reads
`v1.1.2`, like the other PluginsBTW plugins. Nothing else changed: the audio
engine, latency and parameters are the same as in 1.1.1.

![VocalTuneBtw settings page](https://raw.githubusercontent.com/PluginsBTW/VocalTuneBtw/v1.1.2/docs/images/settings.png)

## Download and install

Download `VocalTuneBtw-1.1.2-linux-x86_64.tar.gz` below, then install the
VST3, the CLAP or both:

```bash
tar -xzf VocalTuneBtw-1.1.2-linux-x86_64.tar.gz
mkdir -p ~/.vst3 && cp -r VocalTuneBtw-1.1.2-linux-x86_64/VocalTuneBtw.vst3 ~/.vst3/
mkdir -p ~/.clap && cp VocalTuneBtw-1.1.2-linux-x86_64/VocalTuneBtw.clap ~/.clap/
```

Rescan plugins in your host. Plugin IDs and parameters are unchanged, so
projects saved with earlier versions still load. The archive also contains a
Standalone app (`VocalTuneBtw`) that runs without a host.

Requirements: Linux on x86-64 with glibc 2.43 or newer and libstdc++ from
GCC 13.2 or newer, plus ALSA, FreeType and fontconfig. This build was made on
Arch Linux, so it runs on Arch and other up-to-date rolling distributions.
It won't load on older systems such as Ubuntu 24.04 or Debian 12; there,
build from source.
