VocalTuneBtw: real-time pitch correction for monophonic vocals, built natively
for Linux.

**1.1: cleaner splices and tighter tuning.** The shifter handles moments
without a detected pitch better, a rare click from 1.0 is fixed, and the
pitch is measured twice as often.

![VocalTuneBtw settings page](https://raw.githubusercontent.com/PluginsBTW/VocalTuneBtw/v1.1.0/docs/images/settings.png)

## What's new

- **Cleaner splices without a detected pitch.** On consonants, breaths and
  the start of a note, the detector has no pitch yet. The shifter used to
  jump a fixed distance there, which could make its crossfade dip in level.
  It now jumps to where the waveform matches best. On a real vocal take with
  Detune set to ±100 cents, flagged click events dropped from 18 to 6, and
  the largest remaining ones sit at about −59 dBFS just before a note starts.
- **Fixes a rare click in 1.0.0 and 1.0.1.** When the shift swung far upward
  within about 1 ms right after shifting down (possible with a sparse Custom
  scale at the fastest Retune Speed), the shifter could read audio that
  wasn't written yet. It can't any more.
- **Tighter tuning.** The pitch is now measured every 2.5 ms instead of every
  5 ms, so the correction follows the voice more closely. On the same take at
  Retune Speed 1 ms, the median remaining pitch error drops by about 0.6 to
  1.9 cents. Detection uses about twice the CPU it did, still at most 4.4 %
  of one efficiency core (Intel Core i7-14700K) in the Low range.
- **Quieter keyboard.** Keys outside the scale no longer have a border. Keys
  you switched off keep theirs, so you can see which dark keys can be
  clicked back on.

Latency is unchanged: High 3.8 ms, Normal 6.8 ms, Low 10.8 ms at 48 kHz. The
full measurements are in
[docs/dsp-evaluation.md](https://github.com/PluginsBTW/VocalTuneBtw/blob/v1.1.0/docs/dsp-evaluation.md).

## Download and install

Download `VocalTuneBtw-1.1.0-linux-x86_64.tar.gz` below, then install the
VST3, the CLAP or both:

```bash
tar -xzf VocalTuneBtw-1.1.0-linux-x86_64.tar.gz
mkdir -p ~/.vst3 && cp -r VocalTuneBtw-1.1.0-linux-x86_64/VocalTuneBtw.vst3 ~/.vst3/
mkdir -p ~/.clap && cp VocalTuneBtw-1.1.0-linux-x86_64/VocalTuneBtw.clap ~/.clap/
```

Rescan plugins in your host. Plugin IDs and parameters are unchanged, so
projects saved with earlier versions still load. The archive also contains a
Standalone app (`VocalTuneBtw`) that runs without a host.

Requirements: Linux on x86-64 with glibc 2.43 or newer and libstdc++ from
GCC 13.2 or newer, plus ALSA, FreeType and fontconfig. This build was made on
Arch Linux, so it runs on Arch and other up-to-date rolling distributions.
It won't load on older systems such as Ubuntu 24.04 or Debian 12; there,
build from source.
