VocalTuneBtw: real-time pitch correction for monophonic vocals, built natively
for Linux.

**A new look.** 0.2.0 moves the interface to the shared PluginsBTW style and
makes the note keyboard easier to read. The audio engine is unchanged from
0.1.1, so corrected vocals sound exactly the same.

![VocalTuneBtw correcting an A that is 12 cents sharp](https://raw.githubusercontent.com/PluginsBTW/VocalTuneBtw/v0.2.0/docs/images/note.png)

This is an early prototype. Detection, scale snapping, correction and pitch
shifting work and are covered by automated tests, and it has been used in
Bitwig Studio. It hasn't yet been evaluated systematically on recorded vocals.

## What's new

- **One-octave keyboard.** Each note appears once, C to B, as twelve keys in a
  row. Notes in the scale are lit, the note being corrected is blue, and notes
  you switched off or that aren't in the scale are dark.
- **PluginsBTW style.** The same colours and typeface (Ubuntu Light) as the
  other PluginsBTW plugins, flat surfaces, uppercase captions, and a wordmark
  in three colours.
- **Select boxes and menus.** KEY, SCALE and Voice Range light up on hover,
  and their menus open inside the plugin window with rounded corners.
- **Offline renderer for developers.** `tools/vtb-render` runs a WAV file
  through the engine without a host and reports pitch error and clicks. A new
  test checks the whole engine for clicks on a synthetic sung phrase.

## Download and install

Download `VocalTuneBtw-0.2.0-linux-x86_64.tar.gz` below, then:

```bash
tar -xzf VocalTuneBtw-0.2.0-linux-x86_64.tar.gz
mkdir -p ~/.vst3 && cp -r VocalTuneBtw-0.2.0-linux-x86_64/VocalTuneBtw.vst3 ~/.vst3/
```

Rescan plugins in your host. Plugin IDs and parameters are unchanged, so
projects saved with 0.1.x still load. The archive also contains a Standalone
app (`VocalTuneBtw`) that runs without a host.

Requirements: Linux on x86-64 with glibc 2.43 or newer and libstdc++ from
GCC 13.2 or newer, plus ALSA, FreeType and fontconfig. This build was made on
Arch Linux, so it runs on Arch and other up-to-date rolling distributions.
It won't load on older systems such as Ubuntu 24.04 or Debian 12; there,
build from source (see below).

Only VST3 and Standalone are included. CLAP builds from source but hasn't been
tested in a host yet.
