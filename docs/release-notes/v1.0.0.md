VocalTuneBtw: real-time pitch correction for monophonic vocals, built natively
for Linux.

**1.0: lower latency, and CLAP.** The plugin now delays your audio by 1.8 ms
less in every voice range, and the download includes a CLAP build next to the
VST3 and the Standalone app.

![VocalTuneBtw correcting an A that is 12 cents sharp](https://raw.githubusercontent.com/PluginsBTW/VocalTuneBtw/v1.0.0/docs/images/note.png)

## What's new

- **Lower latency.** At 48 kHz: High 3.8 ms, Normal 6.8 ms, Low 10.8 ms (was
  5.5 / 8.6 / 12.5 ms). The plugin reports the new value to the host, so delay
  compensation adjusts on its own. The crossfade at each splice is now 1 ms,
  and the splice headroom covers shifts up to 3 semitones; larger upward
  shifts start their splice earlier instead of adding latency for everyone.
  This brings back the latency cut that 0.1.1 withdrew: the pops reported
  then didn't come from the plugin. On a real vocal take with Detune at 0,
  offline click measurements match 0.2.0 exactly, and the level stays within
  0.12 dB of 0.2.0. The cost of the shorter delay: at the fastest Retune
  Speed, corrected notes land about 1.5 cents less exactly (median).
- **CLAP.** `VocalTuneBtw.clap` is now part of the release.
- **The logo links to this project.** Click the VocalTuneBtw logo to open the
  GitHub page.
- **Light on CPU.** Measured offline on an Intel Core i7-14700K: at most
  1.1 % of one performance core (2.4 % of an efficiency core) in the Low range,
  less in Normal and High.

The full measurements are in
[docs/dsp-evaluation.md](https://github.com/PluginsBTW/VocalTuneBtw/blob/v1.0.0/docs/dsp-evaluation.md).

## Download and install

Download `VocalTuneBtw-1.0.0-linux-x86_64.tar.gz` below, then install the
VST3, the CLAP or both:

```bash
tar -xzf VocalTuneBtw-1.0.0-linux-x86_64.tar.gz
mkdir -p ~/.vst3 && cp -r VocalTuneBtw-1.0.0-linux-x86_64/VocalTuneBtw.vst3 ~/.vst3/
mkdir -p ~/.clap && cp VocalTuneBtw-1.0.0-linux-x86_64/VocalTuneBtw.clap ~/.clap/
```

Rescan plugins in your host. Plugin IDs and parameters are unchanged, so
projects saved with 0.x still load. The archive also contains a Standalone
app (`VocalTuneBtw`) that runs without a host.

Requirements: Linux on x86-64 with glibc 2.43 or newer and libstdc++ from
GCC 13.2 or newer, plus ALSA, FreeType and fontconfig. This build was made on
Arch Linux, so it runs on Arch and other up-to-date rolling distributions.
It won't load on older systems such as Ubuntu 24.04 or Debian 12; there,
build from source (see below).
