First public release of VocalTuneBtw: real-time pitch correction for
monophonic vocals, built natively for Linux.

![VocalTuneBtw](https://raw.githubusercontent.com/PluginsBTW/VocalTuneBtw/v0.1.0/docs/images/note.png)

This is an early prototype. Detection, scale snapping, correction and pitch
shifting work and are covered by automated tests, and it has been used in
Bitwig Studio. It hasn't yet been evaluated systematically on recorded vocals.

## Download and install

Download `VocalTuneBtw-0.1.0-linux-x86_64.tar.gz` below, then:

```bash
tar -xzf VocalTuneBtw-0.1.0-linux-x86_64.tar.gz
mkdir -p ~/.vst3 && cp -r VocalTuneBtw-0.1.0-linux-x86_64/VocalTuneBtw.vst3 ~/.vst3/
```

Rescan plugins in your host. The archive also contains a Standalone app
(`VocalTuneBtw`) that runs without a host.

Requirements: Linux on x86-64 with glibc 2.35 or newer (Ubuntu 22.04,
Debian 12, Fedora 36 and later, Arch), ALSA, FreeType and fontconfig.

## What's in it

- Key and scale snapping: 12 roots, 14 scales, and per-note on/off on the
  keyboard.
- Retune Speed (1–200 ms) with Natural and Hard presets, Humanize, Strength,
  Detune (±100 cents) and Reference A4 (415–466 Hz).
- Tuning meter with the target note and deviation in cents.
- Latency at 48 kHz: 3.9 ms (High), 7.0 ms (Normal) or 10.9 ms (Low voice
  range), reported to the host for delay compensation.
- Click-free bypass; mono and stereo.

Only VST3 and Standalone are included. CLAP builds from source but hasn't been
tested in a host yet.
