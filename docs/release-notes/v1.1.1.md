VocalTuneBtw: real-time pitch correction for monophonic vocals, built natively
for Linux.

**A new power switch and a tidier window.** 1.1.1 changes only the interface;
the audio engine, latency and parameters are the same as in 1.1.0.

![VocalTuneBtw settings page](https://raw.githubusercontent.com/PluginsBTW/VocalTuneBtw/v1.1.1/docs/images/settings.png)

## What's new

- **Power switch.** The on/off button in the header is now the round
  PluginsBTW power switch: blue while the effect runs, grey while bypassed.
  While bypassed, the tuning meter dims so you can see at a glance that the
  plugin is off.
- **Version in the corner.** The plugin version moved from the settings page
  to the bottom right of the window.
- **More room at the bottom.** The window is 24 px taller (760 × 504), so the
  keyboard no longer touches the window's edge.

## Download and install

Download `VocalTuneBtw-1.1.1-linux-x86_64.tar.gz` below, then install the
VST3, the CLAP or both:

```bash
tar -xzf VocalTuneBtw-1.1.1-linux-x86_64.tar.gz
mkdir -p ~/.vst3 && cp -r VocalTuneBtw-1.1.1-linux-x86_64/VocalTuneBtw.vst3 ~/.vst3/
mkdir -p ~/.clap && cp VocalTuneBtw-1.1.1-linux-x86_64/VocalTuneBtw.clap ~/.clap/
```

Rescan plugins in your host. Plugin IDs and parameters are unchanged, so
projects saved with earlier versions still load. The archive also contains a
Standalone app (`VocalTuneBtw`) that runs without a host.

Requirements: Linux on x86-64 with glibc 2.43 or newer and libstdc++ from
GCC 13.2 or newer, plus ALSA, FreeType and fontconfig. This build was made on
Arch Linux, so it runs on Arch and other up-to-date rolling distributions.
It won't load on older systems such as Ubuntu 24.04 or Debian 12; there,
build from source.
